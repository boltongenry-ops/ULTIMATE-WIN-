# Ultimate Win

Русскоязычная настольная утилита для Windows 10/11 x64. Окно использует WPF и встроенный Windows PowerShell 5.1. Запустите **dist/UltimateWin.exe** из обычного пользовательского сеанса. Для проверки SFC и перезапуска адаптера Windows запросит повышение прав.

Светлую и тёмную темы можно переключать внизу боковой панели. Выбор сохраняется для следующих запусков.

## Работа с Windows

- **Обзор** обновляет загрузку процессора, использование оперативной памяти и выделенной видеопамяти каждые пять секунд, пока окно активно. Данные видеопамяти суммируются по доступным счётчикам драйверов.
- **Процессы** показывает PID, память, описание и наличие главного окна. Фильтр выделяет фоновые программы. Приостановка, возобновление и завершение доступны для подходящих оконных приложений своего сеанса. При обычном закрытии утилита возобновляет приостановленные ею процессы.
- **Автозагрузка** показывает команды Run и RunOnce из реестра и файлы из папок автозагрузки. Выберите строку и нажмите «Удалить из автозагрузки». Команда удаляется из реестра, а выбранный элемент папки перемещается в корзину. Для изменения общих записей Windows может потребовать запуск от имени администратора. **Устройства** показывает присутствующие устройства Plug and Play и коды ошибок диспетчера устройств.
- **Файлы** сканирует выбранную папку или TEMP текущего пользователя. Выберите режим поиска, затем строку для очистки. Файлы отправляются в корзину по одному. Для дубля сохраняется указанный оригинал, хеши SHA-256 сверяются повторно перед удалением. Пустая папка удаляется отдельной нерекурсивной операцией. Большие каталоги требуют больше времени и памяти.
- **Сеть** измеряет трафик каждого активного интерфейса в течение короткого интервала. Доступны очистка кэша DNS и перезапуск выбранного адаптера. Перезапуск прерывает текущие соединения.
- **Диагностика** запускает проверку системных файлов SFC с параметром /verifyonly. Подробности проверки доступны в журнале CBS.

## ИИ-помощник

В разделе «ИИ-помощник» указан базовый адрес OpenCode Go. Введите API-ключ рабочего пространства с активной подпиской Go, нажмите «Загрузить модели» и выберите модель с поддержкой Chat Completions. Идентификатор модели также можно ввести вручную. Для другого совместимого провайдера укажите его базовый HTTPS-адрес. Ключ и переписка хранятся в памяти сеанса.

Провайдер получает историю диалога. Кнопка «Приложить сводку» показывает версию ОС, время работы и нагрузку перед отправкой. Подтверждённая сводка прикрепляется к одному сообщению. Быстрые вопросы можно отредактировать до отправки. Ctrl+Enter отправляет сообщение. Ответ можно скопировать, а кнопка «Новый чат» очищает историю и сохраняет подключение. Для предложенной помощником диагностики, очистки DNS или открытия обзора появится кнопка подтверждения. Поддерживаемые действия определены в приложении.

## Сборка

На машине с Go 1.20+ из корня проекта в PowerShell:

```powershell
$env:GOOS = 'windows'
$env:GOARCH = 'amd64'
go build -trimpath -ldflags="-s -w -H windowsgui" -o dist/UltimateWin.exe .
```

Запускатель включает интерфейс и обработчики из каталога app внутрь EXE.

## Диагностика и управление

- «Почему тормозит ПК?» в диагностике измеряет загрузку CPU, активность диска и использование памяти около 30 секунд. Отчёт показывает средние значения и количество доступных замеров.
- «Проверить соединение» в разделе сети проверяет интерфейсы со шлюзом, ответ первого шлюза на ICMP, DNS и HTTPS для www.microsoft.com. Некоторые шлюзы блокируют ICMP.
- «По папкам» суммирует размеры доступных файлов по каталогам верхнего уровня. Длительные замеры и поиск файлов можно отменить.
- Для команд Run текущего пользователя «Включить / отключить» сохраняет исходную строку и её тип в HKCU под Software\UltimateWin\DisabledRun. Совпадение имён с другой командой блокирует восстановление. Для остальных источников доступна кнопка «Параметры Windows».
- «Объяснить» в процессах, устройствах и автозагрузке переносит сведения о выбранной строке в редактируемый черновик помощника. Отправка выполняется вручную.

Иконка хранится в assets/UltimateWin.ico. Ресурс icon_windows_amd64.syso включается при сборке автоматически. Для обновления используйте rsrc v0.10.2 с параметрами `-arch amd64 -ico assets/UltimateWin.ico -o icon_windows_amd64.syso`.

Перед публикацией ZIP GitHub Actions запускает его на Windows, проверяет загрузку обзора, навигацию и восстановление тестовой записи автозагрузки.

## Диски, драйверы, программы и память

- **Диски.** Разделы сопоставлены с физическим диском по номеру. Видны буквы, типы разделов, файловые системы, размеры и свободное место. В «Накопителях» отображаются состояние и доступные счётчики надёжности. Контроллер или виртуальная машина могут не предоставлять температуру и наработку. «Проверить том» запускает CHKDSK для выбранной буквы в режиме чтения. Отчёт виден до нажатия Enter. Для активного тома результат может зависеть от текущих операций записи.
- **Драйверы.** Поиск по устройству, поставщику и версии. Экспорт стороннего INF через штатный PnPUtil копирует пакет в выбранную папку. Для обновлений доступен переход в Windows Update.
- **Программы.** Список классических приложений из разделов Uninstall текущего пользователя и компьютера, включая 32-разрядные записи. Для MSI запускается интерактивный Windows Installer. Для остальных приложений доступны системные параметры удаления.
- **Память.** Доступная физическая память, кэш, выделение виртуальной памяти, предел выделения, пул ядра и установленные модули. Можно открыть штатный планировщик диагностики памяти Windows.

При выборе функций использованы материалы [RAMMap](https://learn.microsoft.com/sysinternals/downloads/rammap), [CrystalDiskInfo](https://github.com/hiyohiyo/CrystalDiskInfo), [Bulk Crap Uninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller) и документация [CHKDSK](https://learn.microsoft.com/windows-server/administration/windows-commands/chkdsk) и [PnPUtil](https://learn.microsoft.com/windows-hardware/drivers/devtest/pnputil-command-syntax).
